# SPBU//FANTASY first-release branding policy

The first release uses the text mark **SPBU//FANTASY** with the descriptor **Academic Intelligence Layer**. Its visual system is intentionally cyberpunk: deep-black surfaces, electric cyan, neon pink, geometric display typography, HUD corner brackets, and restrained technical lines.

This is a **provisional text-first identity** for the implementation milestone. No official SPBU seal, wordmark, or institutional asset was supplied with the specification. When approved institutional assets are supplied, they should replace the text mark without changing the privacy, authorization, or academic-data semantics of the interface.
