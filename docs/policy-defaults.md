# SPBU Student Fantasy policy defaults

The first release keeps scoring versioned and configurable. The initial draft uses equal EXAM and PASS/FAIL weights, does not apply credit weighting, uses no supplemental fantasy factors until explicitly configured, caps attempts at three, applies no attempt-count weighting in the initial release, and orders ties by academic score, fantasy score, then stable student identifier. Each published ranking row retains the scoring configuration and explanation used to create it.

A Manus-authenticated user is not automatically a student. An administrator links a user account to a student record, the link begins as `pending`, and an administrator explicitly changes it to `verified` or `revoked`. Status changes are audited. Unverified links cannot read academic procedures.

Private mode is the safest peer-visibility boundary. Self-view remains available to the authenticated owner; peer profile, rank, and subject statistics are released only when their corresponding visibility settings permit it. Administrators can operate on protected records, while unauthenticated requests receive no academic data.

The current interface uses the SPBU//FANTASY product mark and a black, cyan, pink, violet, and lime cyberpunk HUD system. Official logo files and final institutional terminology remain replaceable production assets. Payments, live AI generation, public academic records, automatic publication, fabricated content, and unsupported future-faculty data are intentionally outside this first release.
